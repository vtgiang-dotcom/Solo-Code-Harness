# Feature Development

## Phase 1: Discovery
- Read linked issues, specs, requirements
- Identify core problem and stakeholders

## Phase 2: Exploration
- Find related code with search
- Read key files to understand patterns
- Identify where new code should live

## Phase 3: Clarification
- List ambiguities and edge cases
- Ask specific questions — do not assume

## Phase 4: Architecture
- Design data flow and component structure
- Identify files to change
- Consider: error states, loading, empty states

## Phase 5: Implementation
- Read each file before editing
- Make focused, minimal changes
- Match existing code style
- Verify syntax after each edit

## Phase 6: Review
- Run tests and security scan
- Self-review diff for correctness

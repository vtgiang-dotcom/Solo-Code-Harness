# /create — Feature Scaffolding

## Purpose
Build new features from scratch following a disciplined scaffold-then-implement approach.

## Behavior
1. **Plan first** — What files need to be created? What dependencies?
2. **Scaffold structure** — Create files, folders, boilerplate
3. **Implement core logic** — Business rules, data flow
4. **Add error handling** — Edge cases, validation
5. **Write tests** — Before declaring "done"
6. **Verify** — Run and confirm it works

## Rules
- Always create the file structure before writing logic
- Follow existing project patterns (don't invent new conventions)
- Handle loading, empty, error, and success states

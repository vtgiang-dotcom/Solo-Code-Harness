# /brainstorm — Structured Idea Exploration

## Purpose
Activate BRAINSTORM mode for structured idea exploration. Use when you need to explore options before committing to an implementation.

## Behavior
1. **Understand the goal** — What problem? Who is the user? What constraints?
2. **Generate at least 3 options** — Each with pros, cons, and effort estimate
3. **Compare and recommend** — Summarize tradeoffs, give recommendation with reasoning
4. **No code** — This is about ideas, not implementation

## Output Format
```markdown
## Brainstorm: [Topic]

### Option A: [Name]
Pros: ... | Cons: ... | Effort: Low/Medium/High

### Option B: [Name]
Pros: ... | Cons: ... | Effort: Low/Medium/High

### Option C: [Name]
Pros: ... | Cons: ... | Effort: Low/Medium/High

## Recommendation
Option [X] because [reasoning]. What direction?
```

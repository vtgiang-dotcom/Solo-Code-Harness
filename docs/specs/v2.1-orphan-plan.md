## 4. Đề Xuất Thêm Vào BLOCK_PATTERNS

### Nhóm Linux (có nguồn — port ngay)

```js
// v2.1: rm vào thư mục con (opencode.json:11)
{ name: 'rm_relative_wildcard', pattern: /rm\s+-rf?\s+\.\// },

// v2.1: rm -r * (opencode.json:13) — không có -f
{ name: 'rm_r_only', pattern: /rm\s+-r\s+(?!f)/ },

// v2.1: rm -r -f * (opencode.json:14) — flag tách rời
{ name: 'rm_r_f_split', pattern: /rm\s+-r\s+-f\s+/ },

// v2.1: git clean -f (opencode.json:20-22) — gộp -fd, -fx, -f
{ name: 'git_clean_force', pattern: /git\s+clean\s+-f/ },
```

⚠️ Lưu ý `rm_r_only` và `rm_r_f_split`: có thể false positive với `rm -r tmpdir` (xóa thư mục rỗng hợp lệ). Cân nhắc scope hoặc chỉ thêm `rm -r *` rõ ràng. Nếu lo ngại, thay bằng pattern hẹp hơn:
```js
{ name: 'rm_r_wildcard', pattern: /rm\s+-r\s+\*/ },
{ name: 'rm_r_f_wildcard', pattern: /rm\s+-r\s+-f\s+\*/ },
```

### Nhóm Linux (không nguồn — đề xuất, chờ duyệt)

```js
// v2.1: rm thư mục hệ thống (đề xuất mới)
{ name: 'rm_system_dir', pattern: /rm\s+-rf?\s+\/(?:etc|usr|var|bin|lib|boot|sbin)(?:\/|\s|$)/ },

// v2.1: curl | sh — nâng cấp từ WARN gate-guard.js:49 lên BLOCK
{ name: 'curl_pipe_shell', pattern: /curl\s+.*\|\s*(?:ba)?sh/ },
```

### Nhóm Windows (có nguồn — port ngay)

```js
// v2.1: rd /s (opencode.json:39) — /i cho flag
{ name: 'win_rd_recursive', pattern: /(?:rd|rmdir)\s+\/[s]/i },

// v2.1: del variants — /q, /s, /f (mở rộng win_del_force hiện tại)
// Cẩn thận: /q và /s có thể đảo thứ tự
{ name: 'win_del_any', pattern: /del\s+\/[qsf]/i },

// v2.1: Format-Volume (opencode.json:45)
{ name: 'win_format_volume', pattern: /Format-Volume\b/ },

// v2.1: Stop-Computer (opencode.json:46)
{ name: 'win_stop_computer', pattern: /Stop-Computer\b/ },

// v2.1: Restart-Computer (opencode.json:47)
{ name: 'win_restart_computer', pattern: /Restart-Computer\b/ },
```

⚠️ Lưu ý win_del_any: pattern `del \/[qsf]` sẽ match bất kỳ flag q/s/f nào, bao gồm `del /q path`, `del /s path`, `del /f path`, và cả `del /q /s path`. Đây là mở rộng từ `win_del_force` hiện tại.
